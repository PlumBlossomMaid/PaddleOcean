===================================
PaddleOcean Documentation
===================================

**PaddleOcean** is a high-level PaddlePaddle framework inspired by
PyTorch Lightning — Trainer, Model, Callbacks, Loggers, DDP, Gear,
VisualDL. Built entirely with PaddlePaddle native APIs, zero PyTorch
dependencies.
