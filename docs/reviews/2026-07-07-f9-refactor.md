# Ocean F9 根因重构：按 stage 分离的结果收集

- **日期**：2026-07-07
- **起因**：loops review 的 **F9**（metrics buffer 未按 stage 分离）+ connectors review 的 F9-a~F9-e。见 `2026-07-06-loops-review.md`、`2026-07-07-connectors-review.md`。
- **对照参考**：`logger_connector/`（`logger_connector.py` + `result.py` 的 `_ResultCollection`）
- **主分支状态**：`master @ 35a6712`；本次工作分支 `fix/logger-result-collection`

## 做了什么

把散落两处、无 stage 维度的 metrics buffer，替换为按运行阶段分离的结果收集，行为对齐参考实现。

### 新增（Paddle 原生 `_ResultCollection`）
- `ocean/trainer/connectors/logger_connector/result.py`
  - `_Metadata`：记录 `fx`/`name`/`on_step`/`on_epoch`/`reduce_fx`；校验 reduce_fx ∈ {mean,sum,min,max}；`forked_name` 支持 `_step`/`_epoch`。
  - `_ResultMetric`：按 reduce 累积。mean 为 **batch_size 加权**（`Σ(value·bs)/Σbs`）——修复 F9-c 的无权重均值；min/max/sum 各自归约；`paddlemetrics.Metric` 委托其 `.compute()`。
  - `_ResultCollection(training: bool)`：以 `fx.name` 为键；`metrics(on_step)` 返回 `{callback,log,pbar}`（log 受 `logger=` 门控，callback 训练期/epoch 期可读，pbar 受 `prog_bar=` 门控）；`reset(fx=)` 按 fx 精确重置。
- `ocean/trainer/connectors/logger_connector/logger_connector.py`：`_LoggerConnector` 重写为**委托** `trainer._results` 存储，只保留 logger 配置/分发 + 快照 dict 刷新。
- `ocean/trainer/connectors/logger_connector/__init__.py`：子包导出。

### 删除（死代码 / 两套 buffer，F9-b）
- 旧 `_LoggerConnector._metrics_buffer` + `update_train_step_metrics` + `update_train_epoch_metrics`（零调用死代码）。
- `Trainer._log_metrics_buffer`（defaultdict）+ `_metric_objects`；`_compute_epoch_metrics` 改为从 `_results` 拉取 epoch 视图。

### 按 stage 切换 collection（F9-a、F9-d 根因）
- `fit_loop.py`：fit 开始 + **每个 epoch 开始**建 `training=True` 收集（epoch 加权均值独立）。
- `training_epoch_loop.py._run_validation`：mid-epoch val **换入独立** `training=False` 收集，`try/finally` 里丢弃并**还原训练收集**——训练累积再也不会被 val 清空。
- `evaluation_loop.py`：validate/test 用独立 `training=False` 收集。
- `Trainer._sanity_check`：sanity 用一次性 `training=False` 收集，结束还原——sanity 指标不再泄漏进训练态（旧扁平设计的隐性泄漏）。
- 每个 batch 把 `batch` 挂到收集上以支持加权。

## 对照参考的行为对齐点（含一处刻意偏离）

| 行为 | 参考 | 本次实现 |
|---|---|---|
| train/val 指标隔离 | 各自 `_ResultCollection` | ✅ 同（按 stage 切换 `trainer._results`） |
| epoch mean | batch_size 加权 | ✅ 同 |
| min/max/sum reduce | 支持 | ✅ 同 |
| `logger=False` 指标去向 | `callback_metrics`，不进 `logged_metrics` | ✅ 同（连带把 LR-plateau 的 monitor 读取从 `logged_metrics` 改为 `callback_metrics`，对齐参考） |
| 名称 fork（`x_step`/`x_epoch`） | 默认开启 | ⚠️ **刻意偏离**：Ocean 公开 `Model.log` 契约是裸名（现有测试 `test_metrics.py:119` 用 `on_step=on_epoch=True` 却断言裸名 `train_acc`）。收集**保留** fork 能力（`fork_names=True`，单测覆盖），但 Trainer 构造时传 `fork_names=False` 维持裸名契约。 |
| 跨 rank sync | `compute()` 时 sync tensor | Paddle 因地制宜：sync 已在 `_log_metric` 上游按值完成，收集内只存标量，DDP 行为不变 |
